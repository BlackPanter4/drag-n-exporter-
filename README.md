# 🐉 Dragon Exporter

Plugin WordPress hecho desde Luchanas, Coahuila.

Exporta tus datos con efecto Drag-n-Drop. Fácil, rápido y ligero.

**Autor:** BlackPanter4 - Full Stack Developer
**Versión:** 1.0

## 🚀 Características
- Arrastrar y soltar
- Exporta a CSV
- Ligero y rápido
- No necesita librerías extra

## 📦 Instalación
1. Descarga el ZIP
2. WordPress > Plugins > Añadir nuevo > Subir plugin
3. Activa y verás el menú 🐉 Dragon

Hecho con 🔥 desde Coahuila para el mundo.
